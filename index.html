About

I'm an embedded firmware engineer at Xcelerium in Lahore, working on custom RISC-V SoCs. I develop SDK components (HAL and drivers), PCIe and DMA firmware, and a bare-metal multi-core test suite that checks interrupts, cache coherency and atomics on real silicon.

I came to firmware through hardware design. At university I built RTL for processors and accelerators, including a vector co-processor for my final year project, so I'm most at home where hardware and software meet. I'm especially interested in computer architecture, vector processing and memory systems.

Projects

Final year project

Vector co-processor with a custom VLSU

SystemVerilog · Verilator

A fully functional Vector Load/Store Unit (VLSU) that works with a scalar processor to handle memory-intensive vector operations over AXI4.

  • Supports unit-stride, strided and indexed memory access.
  • CSR-based configuration of vector length and type (VLEN, LMUL, vl, vtype).
  • Ready and acknowledge handshakes between the scalar core and the co-processor.
  • Checked through waveform simulation of vector load and store instructions.

5-stage pipelined RISC-V scalar processor

SystemVerilog

A scalar RISC-V core supporting R, I, S, B, U and J-type instructions.
