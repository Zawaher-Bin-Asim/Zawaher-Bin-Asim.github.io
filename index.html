About

Where hardware meets software

I am an embedded firmware engineer at Xcelerium in Lahore, writing and validating firmware for custom RISC-V SoCs. My work covers SDK drivers, PCIe and DMA firmware, and a bare-metal multi-core test suite for interrupts, cache coherency and atomics.

Before that I designed and verified RTL at university, including a vector co-processor for my final year project. I have booted Linux and Zephyr on custom RISC-V cores, and I enjoy the point where hardware and software meet.

I am looking for a PhD where I can work on processor and memory-system design.

Selected work

Final year project

Vector Co-Processor with a custom VLSU

SystemVerilog · Verilator

A fully functional Vector Load/Store Unit (VLSU) that works with a scalar processor to handle memory-intensive vector operations over AXI4.

  • Supports unit-stride, strided and indexed memory access.
  • CSR-based configuration of vector length and type (VLEN, LMUL, vl, vtype).
  • Ready and acknowledge handshakes between the scalar core and the co-processor.
  • Checked through waveform simulation of vector load and store instructions.

5-stage pipelined RISC-V scalar processor

SystemVerilog

A scalar RISC-V core with the full set of R, I, S, B, U and J-type instructions.

  • Hazard detection, forwarding and load-use stalls.
  • UART with interrupt-based transfers.
  • CSR-based exception unit for external and timer interrupts.
